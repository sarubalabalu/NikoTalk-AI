# 🗣️ NikoTalk AI
## 🚀 Live Demo

👉 [Try NikoTalk AI](https://nikotalk-ai-p9qi2mgejs4ww8apvngx7k.streamlit.app/)

NikoTalk AI is an English communication learning application built using Python and Streamlit.

## ✨ Features

- 📚 Vocabulary Practice
- 📖 Grammar Practice
- ✍️ Sentence Formation
- 💬 Daily Conversation
- 📋 Simple English Rules
- 📖 Story Understanding
- 🎤 JAM - Just A Minute
- 🖼️ Presentation Practice
- 🗣️ Pronunciation Practice
- 🎙️ Voice Recording
- 🤖 Speech Analysis
- 📊 Speaking and Pronunciation/Clarity Scores

## 🛠️ Technologies

- Python
- Streamlit
- Pandas
- SpeechRecognition
